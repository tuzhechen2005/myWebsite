# 纸海 · The Paper Sea — 涂喆宸作品短片 (≈95 s, 16:9)

**Logline:** 一滴墨落进米白纸面的海，化成小水母 Jelly。问题从海面一个个沉下来，Jelly 想帮忙，却总有「随手编一个答案」的诱惑。
于是它一章一章地学会：先找依据，再回答，找不到时就诚实地交给人。

**One world:** 纸海。浅海就是米白纸本身（留白即海水），越往深处越接近网站的深墨绿 `#17312D`。
主色是木版画式的平涂色块加墨线：墨绿、朱红珊瑚、金、鼠尾草绿，外加一点紫丁香点缀。只有深海里有光（`glow()`）。
**色彩弧线：** 纸白（序）→ 档案馆暖纸 → 诊所的鼠尾草绿 → 工具墙的赭金 → 深海墨绿（高潮）→ 回到纸白（尾，与开场押韵）。
**Motif:** 金色的线，也就是 Jelly 的溯源触手。第一章用它把答案挂回出处，第四章用它把证据缝到蝴蝶翅膀上，片尾用同一根线写下落款（只用英文：中文毛笔字体里没有「喆」字）。
**问题 = 漂流瓶：** 瓶里画着图标（问号、文档、表格、工具），从海面沉下来。高潮章节里，问题换成一只纸蝴蝶，因为甲状腺就是蝴蝶形的。
**Rhyme:** 开场是一滴墨落进纸里，漾开一圈圈涟漪；结尾 Jelly 在水面写完落款，潜回水里，留下同样的一圈圈涟漪。

**Cast**
- **Jelly**：珊瑚朱红的水母。钟形伞体会随节拍收缩和舒张（游泳时的挤压与拉伸），6 根触手有跟随和拖曳，两根「手」触手可以抓东西；脸用引擎的眼睛和嘴。
- **四只小水母**（第二章分身）：采集（赭金，拿夹板）、检索（鼠尾草绿，拿书页）、导诊（紫丁香，拿路牌）、护栏（石板蓝，拿盾牌和红旗）。
- **海马**：赭黄色的小病人。**章鱼外科医生**：墨绿色，戴手术帽和口罩，就是人类医生（HITL）。
- **鳗鱼**：拿着万能钥匙的小坏蛋（不安全的 SQL）。

**节拍**：96 BPM，一拍 0.625 s，一小节 2.5 s。配乐由代码合成，和画面共用 `src/cues.js`。

## Build notes
- 代码：`src/scenes/sea_set.js`（世界、角色、道具、翻页转场）+ 每章一个文件 `c0_prologue.js` … `c4_thyroid.js`（尾声和第四章在同一个世界坐标里）。
- 时间轴：`src/cues.js`。场景和 `music/score.mjs` 读的是同一份时间轴。
- 配乐：`node music/score.mjs` → `music/score.wav`（已 gitignore）→ EQ 加 loudnorm 编码成 `assets/score.m4a`（-16 LUFS）。
- 成片：`node render.mjs --frames --workers=4 && node render.mjs --encode --audio=assets/score.m4a --out=out/video.mp4`，
  然后压缩成网页版，放进 `../site/assets/showreel/`（见仓库 CLAUDE.md）。
