多智能体医疗预问诊与导诊系统Multi-Agent Medical Pre-Consultation & Triage System

面向常见科室的医疗预问诊与导诊系统，多 Agent 协作完成结构化采集与分诊，定位决策支持，不做诊断与处方。 A pre-consultation and triage system for common clinical departments. Multiple agents collaborate on structured intake and triage — positioned for decision support, never diagnosis or prescription.

  • 分层多智能体架构：基于 LangGraph，由协调 Agent 统一调度问诊采集、知识检索、分诊导诊与安全护栏等专职 Agent。Layered multi-agent architecture: a coordinator agent on LangGraph orchestrates specialized agents for intake, retrieval, triage, and safety guardrails.
  • 动态采集：依据已采集症状决定追问与工具调用；12 个常见科室测试中关键信息完整度由约 70% 提升至 92%，平均轮次由 12 降至 6.5。Dynamic intake: follow-ups and tool calls adapt to symptoms; across 12 tested departments, key-info completeness rose from ~70% to 92% and average rounds fell from 12 to 6.5.
  • RAG 工具化：接入 300+ 篇临床指南，通过 JSON Schema 与 Pydantic 约束工具输入输出，回答可溯源率 90%+。RAG as a tool: indexed 300+ clinical guidelines, constrained tool inputs and outputs with JSON Schema and Pydantic, and achieved 90%+ traceable answers.
  • 安全护栏 + HITL：急症红旗识别、越界请求拒绝、事实一致性二次校验；自建约 180 条评测集追踪表现。Safety guardrails + HITL: emergency red-flag detection, out-of-scope refusal, and consistency re-checks, tracked on a ~180-case eval set.

企业级 RAG AI 智能助手Enterprise RAG AI Assistant

统一接入结构化数据库与非结构化文档的 RAG 问答系统，自然语言驱动数据查询与知识检索。 A RAG Q&A system unifying structured databases and unstructured documents, with natural-language-driven data querying and knowledge retrieval.

  • 路由与检索：BM25 + Qwen3-Embedding-4B 融合召回，经 DistilBERT 分流文档 / SQL / 混合查询，路由准确率 93%。Routing and retrieval: BM25 + Qwen3-Embedding-4B fusion with DistilBERT document / SQL / hybrid routing at 93% accuracy.
  • 级联重排：Qwen3-Reranker-4B 精排使 500 条评测集上的复杂查询 Recall@10 提升 18%、Top-5 相关性提升 20%，检索耗时低于 120ms。Cascade reranking: Qwen3-Reranker-4B improved complex-query Recall@10 by 18% and Top-5 relevance by 20% over 500 evaluations, with retrieval under 120ms.
  • 安全与上下文：JWT / RBAC 检索前 ACL 过滤，权限测试中越权 0 例；200 条对抗样本中危险 SQL 拦截率 100%。Security and context: pre-retrieval JWT / RBAC ACL filtering yielded zero unauthorized accesses in permission tests; dangerous SQL was blocked in 100% of 200 adversarial cases.
  • 并发与评测：Milvus + Redis + asyncio 支撑 200 并发，P95 延迟下降 30%+；回答可溯源率 92%。Concurrency and evaluation: Milvus + Redis + asyncio handled 200 concurrent requests with 30%+ lower P95 latency; answer traceability reached 92%.

用合成文档演示 RAG 系统中的两种路径：有来源时引用，没有足够来源时拒答。这是流程示意，不是实时模型或医疗建议。Two paths through a RAG workflow using synthetic documents: cite a source when one exists, or abstain when evidence is insufficient. This is an illustrative workflow, not a live model or medical advice.
