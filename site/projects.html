多智能体医疗预问诊与导诊系统Multi-Agent Medical Pre-Consultation & Triage System

面向常见科室的医疗预问诊与导诊系统，多 Agent 协作完成结构化采集与分诊，定位决策支持，不做诊断与处方。 A pre-consultation and triage system for common clinical departments. Multiple agents collaborate on structured intake and triage — positioned for decision support, never diagnosis or prescription.

  • 分层多智能体架构：基于 LangGraph，由协调 Agent 统一调度问诊采集、知识检索、分诊导诊与安全护栏等专职 Agent。Layered multi-agent architecture: a coordinator agent on LangGraph orchestrates specialized agents for intake, retrieval, triage, and safety guardrails.
  • ReAct + Plan-and-Execute：依据已采集症状动态决定追问与工具调用，替代固定表单，关键信息完整度 70% → 90%+。ReAct + Plan-and-Execute: dynamically decides follow-ups and tool calls from collected symptoms — replacing fixed forms; key-info completeness rose from 70% to 90%+.
  • RAG 工具化：将自研 RAG 封装为检索工具接入临床指南知识库并提供引用溯源，回答可溯源率 90%+。RAG as a tool: wrapped a custom RAG system as a retrieval tool over a clinical-guideline knowledge base with citation tracing — 90%+ traceable answers.
  • 安全护栏 + HITL：急症红旗识别、越界请求拒绝、事实一致性二次校验；自建约 180 条评测集追踪表现。Safety guardrails + HITL: emergency red-flag detection, out-of-scope refusal, and consistency re-checks, tracked on a ~180-case eval set.

企业级 RAG AI 智能助手Enterprise RAG AI Assistant

统一接入结构化数据库与非结构化文档的 RAG 问答系统，自然语言驱动数据查询与知识检索。 A RAG Q&A system unifying structured databases and unstructured documents, with natural-language-driven data querying and knowledge retrieval.

  • 问题理解链路：集成 Query Rewrite / Decompose / HyDE 提升复杂查询召回，复杂查询 Recall@10 提升 18%。Query understanding: Query Rewrite / Decompose / HyDE for complex queries — Recall@10 up 18%.
  • 检索路由：按问题类型与意图自动选择 Text-to-SQL 或语义检索路径，平均查询响应时间降低 35%+。Retrieval routing: auto-selects Text-to-SQL or semantic paths by intent — avg query latency down 35%+.
  • 混合检索 + Chunking：BM25 + Dense Retrieval + Cross-Encoder 重排使 Top-5 相关性提升 20%+；语义边界切分 + 滑动窗口增强上下文。Hybrid retrieval + chunking: BM25 + dense + Cross-Encoder reranking lifted Top-5 relevance 20%+; semantic-boundary chunking with sliding windows.
  • 评测与自校验：Retrieval Feedback 迭代 + LLM Self-Reflection 校验，回答事实一致性提升 15%+，高风险场景幻觉率下降 20%+。Eval & self-check: retrieval-feedback iteration + LLM Self-Reflection — factual consistency up 15%+, high-risk hallucination down 20%+.

AI 增强型知识社区平台AI-Enhanced Knowledge Community Platform

结合高并发后端架构与 RAG 智能问答的知识社区，支持内容发布、实时数据处理与智能检索问答。 A knowledge community combining a high-concurrency backend with RAG-powered Q&A — content publishing, real-time processing, and intelligent retrieval.

  • 事件驱动架构：Kafka + Outbox 解耦用户关系、计数系统与 Feed 流，保障高并发下数据一致性。Event-driven architecture: Kafka + Outbox decouples relationships, counters, and feeds — consistency under high concurrency.
  • 高并发计数：Redis 结合位图判重与 Lua 原子操作，实现点赞 / 关注的幂等高并发写入。High-concurrency counting: Redis with bitmap dedup and atomic Lua scripts — idempotent like/follow writes at scale.
  • 多级缓存：Caffeine + Redis 结合 hotkey 探测与 single-flight，规避缓存击穿与雪崩。Multi-level cache: Caffeine + Redis with hotkey detection and single-flight to prevent cache stampede and avalanche.
  • 搜索与问答：Elasticsearch（BM25 + 业务权重）支持检索与联想；集成 RAG 问答降低幻觉；JWT 双令牌支持会话续期与实时失效。Search & Q&A: Elasticsearch (BM25 + business weighting) for search and suggestions; integrated RAG Q&A; JWT dual-token for renewal and instant revocation.
